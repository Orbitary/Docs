# PacketNinja - Packet Debugging for Minecraft

🥷 **PacketNinja** is a powerful utility mod designed to make packet debugging during Minecraft development easier and more intuitive. With beautiful formatting and flexible filtering, understanding packet flow has never been simpler.

## Features

### Pretty Packet Formatting

PacketNinja makes packets readable with structured formatting:

```
[C→S] ServerboundInteractPacket
├─ Entity ID: 12345
├─ Action: ATTACK
└─ Hand: MAIN_HAND
```

### Supported Packets

Currently supported with full formatting:

**Clientbound:**
- ClientboundAddEntityPacket
- ClientboundCustomPayloadPacket
- ClientboundRemoveEntitiesPacket
- SetPassengersHandler

**Serverbound:**
- ServerboundInteractPacket
- ServerboundPlayerActionPacket
- ServerboundSwingPacket

:::note[Active Development]
PacketNinja is under active development. More packet types are being added regularly!
:::

### Filtering System

<ExperimentalBadge />

Filter packets based on various criteria:
- Packet type
- Direction (clientbound/serverbound)
- Custom filters
