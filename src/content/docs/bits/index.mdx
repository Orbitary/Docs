# Bits - Multi-Platform Minecraft Utility Library

<PlatformBadge platforms={['all']} />

Bits is a comprehensive utility library designed to streamline Minecraft plugin and mod development across multiple platforms. With a unified API, annotation-driven commands, and extensive utilities, Bits helps you write less boilerplate and focus on building great features.

## Features

### Command Framework
Build commands with simple annotations that compile to efficient Brigadier commands:

```java
@Command(name = "teleport")
@Permission("server.teleport")
public class TeleportCommand {
    public void execute(@Sender Player player, Location location) {
        player.teleport(location);
    }
}
```

### Text Formatting
Automatic support for MiniMessage and legacy color codes:

```java
player.sendMessage("<gradient:blue:green>Beautiful gradient text!");
player.sendMessage("&aLegacy colors work too!");
```

### Multi-Platform Support
Write your code once, deploy it everywhere. Bits abstracts platform differences, giving you a unified API.
