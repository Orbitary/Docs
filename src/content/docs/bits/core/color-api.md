# Color API

<PlatformBadge platforms={['all']} />
<ComingSoon message="Full color API documentation coming soon" />

The Color API provides utilities for working with colors across different platforms and formats.

## Features

- RGB color support
- Hex color codes
- Named colors
- Color gradients
- Platform-specific conversions

## Basic Usage

```java
// Create colors
Color red = Color.fromRGB(255, 0, 0);
Color blue = Color.fromHex("#0000FF");

// Use in text
player.sendMessage(red.apply("This is red text"));
```
