# Math Utilities

<PlatformBadge platforms={['all']} />
<ComingSoon message="Math utilities documentation coming soon" />

Bits includes a collection of mathematical utilities to make common calculations easier.

## Features

- Vector mathematics
- Geometric calculations
- Random number generation
- Common math operations

## Basic Usage

```java
// Vector operations
Vector3D result = vector1.add(vector2);
double distance = vector1.distance(vector2);

// Random utilities
int random = MathUtil.randomInt(1, 100);
```
